Featured Project

쿠쿠 렌탈

Rental Admin System & Mobile App

Overview

렌탈 업무를 위한 관리자 시스템과 직원용 모바일 앱 UI 구축 프로젝트입니다.

Vue 기반으로 관리자 시스템의 공통 UI와 복잡한 업무 화면을 구현하고, PrimeVue DataTable을 요구사항에 맞게 커스터마이징했습니다. 모바일 앱에서는 모바일 사용 환경을 고려한 UI를 구축했습니다.

01

Admin UI Architecture

Challenge

관리자 시스템 특성상 여러 화면에서 유사한 검색 조건과 입력 UI가 반복되고, 화면마다 데이터 구성과 레이아웃에는 차이가 있었습니다.

Approach

반복되는 UI와 화면별 차이를 분석해 공통화할 영역과 개별 처리할 영역을 구분했습니다.

Implementation

  • 반복되는 검색 조건을 공통 UI로 구성
  • 동일한 입력 구조를 페이지와 팝업에서 재사용
  • 화면 구성에 따라 유연하게 사용할 수 있는 UI 구조 설계

Result

반복 구현을 줄이고 화면 간 UI 일관성을 확보했습니다. 공통 영역 수정 시 여러 화면에 동일하게 반영할 수 있도록 유지보수성을 개선했습니다.

02

DataTable Customization

Challenge

관리자 시스템의 대량 데이터를 효율적으로 확인하고 사용자가 업무 환경에 맞게 테이블을 조정할 수 있어야 했습니다.

Approach

PrimeVue DataTable의 기본 기능을 검토하고 요구사항별로 필요한 인터랙션과 커스터마이징 범위를 분석했습니다.

Implementation

  • Drag & Drop
  • Column Resize
  • Column Reorder
  • 프로젝트 UI에 맞춘 DataTable 스타일 및 동작 커스터마이징

Result

업무 특성에 맞게 테이블을 조작할 수 있는 관리자 UI를 구현했습니다.

03

Responsive Layout / Mobile UI

Challenge

PC 관리자 시스템과 모바일 앱이라는 서로 다른 업무 환경에 맞는 UI가 필요했습니다.

Implementation

Admin
  • 다양한 화면 구조에 대응하는 레이아웃
  • Split Layout / Resizer
  • LNB 상태에 따른 콘텐츠 영역 대응
  • 내부 스크롤 및 높이 제어
Mobile
  • Top App Bar
  • Bottom Navigation
  • Floating UI
  • 모바일 환경에 최적화된 화면 구성
